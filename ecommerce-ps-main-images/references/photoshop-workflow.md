# Photoshop执行、保存和验证

## 环境与文档所有权

使用实际探测到的PS和解释器，不硬编码某台盘符。JSX可由宿主支持的PS工具、Windows已允许的自动化或PS“文件→脚本→浏览”执行；不要为追求某条调用路线修改安全设置。没有可用自动执行能力时准备可手动运行的脚本，并如实标注尚未运行。

首次只在任务新文档做 smoke test：`scripts/smoke_test.jsx`。本次执行的新复杂动作也先测一个样例。记录PS版本、已有文档ID/保存状态、字体PostScript名。PS修改顺序执行；等待完成日志再运行下一脚本，不并发操控同一PS。

任务开始保存并最终恢复 rulerUnits、对话框偏好和原活动文档；坐标和字号使用像素，显式 `UnitValue(...,'px')`。不得保存、改动或关闭用户已有/未保存/手改文档。只关闭有所有权记录且输出已保存核对的任务中间文档。报错保留阶段、行号和异常；检查PS模态提示，不反复重启脚本叠加任务。

## 固定布局执行

阅读[布局格式](layout-schema.md)，按每页量取结果填写布局文件。编译器只把确定的JSON转为JSX，不负责识字、理解参考或自动提取商品。

```text
python render_layout.py page.layout.json --out page-r1.jsx --skeleton --output-dir skeleton-r1
python render_layout.py page.layout.json --out page-r2.jsx --output-dir rendered-r2
```

Windows且当前解释器已有pywin32时，可统一用 `python scripts/run_photoshop.py page-r2.jsx --status rendered-r2/页面job_id.status.json` 执行并核对完成状态；骨架文件名含 `_skeleton`。此工具不会安装依赖、重启或关闭PS。没有COM能力时用宿主实际PS工具或“文件→脚本→浏览”，仍检查状态文件。无需每次临时重写一套PS启动代码。

上面 `python` 表示已经验证可用的解释器；路径按实际环境替换。spec中的图片路径相对spec文件；项目记录中的layout路径相对项目根，这两者不能混淆。输出使用新版本路径，不覆盖用户手改PSD。编译成功≠PS运行成功；PS保存成功≠设计通过。

原生文字、照片嵌入智能对象、图框蒙版、背景与装饰分层。图片 contain 保持完整比例；cover 等比放大后按框蒙版裁切，不能只放大导致越界。透明产品素材保持实物轮廓；去背由素材处理或PS蒙版实现，不用矩形图框伪装去背。

旋转、字距、行距、描边、阴影在实际字体和目标尺寸下核查。双描边/反射/曲线字/纸片变形/复杂路径等若编译器不支持，不能删掉效果来通过校验；用自建PS组件或原生手工操作实现，再把关键参数与对象ID写入项目记录。替换整张平面参考、把字栅格化或叠一层不可编辑整图，都不能称为原生复刻。

## 易出错动作

- 图层遍历按ID读描述符；不要靠反复设置activeLayer判断可见性，避免隐藏备选素材被激活。复制前后保留root visibility并重渲染整页。
- 跨文档复制需显式激活文档，以源bounds校正位置；LayerSet移动不支持时用已测试的根层分组方式，不默认所有PS版本行为相同。
- 给带蒙版的对象模糊时核对选中的是RGB还是蒙版；输出确认所需区域确实变化。
- 替换智能对象保留变换不代表新素材自然适配；新比例、轮廓和原蒙版都重查。
- saveAs可能改document.name；基名提前固定，以路径和文档ID确认身份。重新打开交付副本时核实fullName，防止查到旧位置已打开的文档。
- 单模块构建成功后再扩展；完整批次中断只恢复失败阶段，不重复已保存部分。字体不可见不能自动强退PS。

## 原生整页与导出

详情同时保留独立分屏与按模块分组的原生整页；整页的文字仍可改、照片仍可替换。不能把所有分屏JPG粘进长PSD冒充原生整页。超出PSD实际能力时优先按合理工作宽度制作；确需PSB要说明并保留独立分屏PSD，不能静默扁平化。

同步导出对应JPG/PNG，保持正确色彩和尺寸。跨分屏复制易偏移时先测一处接缝；可以由完整原生文档副本按记录裁切导出，不能改变用户原稿。大文档资源不足先停止重复批次，保护已有输出；不要删除未知暂存文件或全局清理历史。

## 本任务必须留下的技术证据

对代表成品PSD保存、关闭任务副本、从实际交付路径重开，记录原生文字数、嵌入智能对象/蒙版、实际字体与画布；在另存测试副本中改一个文字、替换一张素材，再导出查看变化且未破坏布局。这个动作验证可编辑性，不自动批准其他页的设计。

每张输出仍查文件存在、尺寸、源文件配对及版本；完整详情看整条与接缝。有缺失字体、外链素材、存错位置、原生对象丢失或页面越界时修正后重验，不以文件大小/数量当完成证据。
