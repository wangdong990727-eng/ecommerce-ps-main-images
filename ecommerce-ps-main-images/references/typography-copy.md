# 原文、事实与字体分开处理

严格复刻默认：保留适合本品的表达方式、字级、行数和节奏，替换必要事实、品牌及不能复用的素材；普通适用文案尽量保留，不自行重写整套营销。参考中的断行、标点、强调字和倾斜都属于排版记录。用户确认可复用的图标直接提取，图形与文字分开处理，按[国内制作要求](commerce-compliance.md)执行；其他未获允许的标识、独创图形与素材用已获授权内容或自行制作的同职责元素替代，并记录差异。

## 文案事实表

在项目页的 `copy` 中逐个文字对象保存：`id / reference_text / final_text / change_reason / fact_sources`。未改时 final 与 reference 完全一致，change_reason 可空。改动时写具体原因，不用“优化表达”掩盖自由创作。

- 品牌/型号/产地/材质/尺寸/尺码/性能/洗护/适用人群以本品证据为准。同行参数不是本品参数。
- 没有依据的功能用本品已证实、同等篇幅的结构事实替换；如果连对应事实也没有，该处留待审占位并记录阻塞，不编造。
- 品牌字样、认证、销量、买家评价、专利等不因“逐字”要求自动成为本品声明。优先真实本品信息；没有则保留布局位置并明确待处理。
- 用户授权暂用的参数只进入注明状态的审阅稿；正式可上架文件中不得藏未知值。待确认说明放报告，不混进商品图假装已核实。
- 品牌标识、实物印花使用本品原始素材；不要保留同行标志或让模型绘字。

只替必要事实后长度发生变化，先在相同字号级别、字距/行距和文字框内校准；尽量保持原行数和行末节奏。明显容不下时记录两版（保原句/轻微事实重排）供集中审阅，不擅自换掉整体版式。不能把字体压扁到变形来假装一致。

## 全语言与图文联合复审

在copy检查记pass前，运行 `scripts/audit_copy.py <项目> --out <新审查.json>`；局部修改可用 `--pages <页ID...>`。它只核对台账、布局与可用的PSD文字证据，并列出所有语言的文字及非文字层，不会判定宣称真实、图标含义或视觉通过。关键词提醒不穷尽，未提示也要逐对象阅读。

按同一宣称联查中文、英文、小字、角标、图标、照片暗示。中文因缺性能依据而修改时，同步查英文翻译和原图标；“只是装饰”不能豁免。普通品名与已确认成分不机械删除；成分只许放参数栏等用户限定的使用位置仍须遵守。图标改变语义时仅替换对应图形，记录事实差异，保留其他参考版式。

尺寸分两项核对：数值及来源正确；图示的被量对象、方向、端点正确。耳包直径不等于整件高度；透视照片不能当量尺实测。没有清晰端点时仅保留文字说明，或补真实测量图，不能随意画一条看似精确的尺寸线。复审证据说明每项实际看见什么及未解决项，不因脚本一致而升级copy/product/layout状态。

## 识别字体与复现效果

先分清字形和效果：手写/衬线/黑体、细/粗/超粗、窄/宽、真斜体/旋转、描边、双描边、阴影、发光、纸条、笔刷底。原图已倾斜不等于整段仅做旋转；记录文字基线和字形倾斜的区别。

查PS字体列表取得实际 PostScript 名；默认优先现有免费商用许可明确的同款。缺失时按[字体许可与候选](commerce-compliance.md)查官方样张及具体版本许可，选择字形最接近的免费商用字体，用实际文案排一小段和参考并排比较，不能一律退到黑体。可以用PS原生变换/字距调整等方式校准，但不要把正文栅格化。不能保留截图里的受限字体来绕过本次字体要求。

字体不可识别时如实标注“近似字体”；严格完全相同需要拿到同款字体或可编辑参考源文件，这是输入条件，不是提示词能够保证。缺字/替代字体/字重错误必须在成图中检查；字号数字相同不代表视觉大小相同。

只在已有授权范围内下载和用户级安装免费、商用许可明确的字体；不自动购买、索要提权或重启PS。当前任务未授权安装时先用合规可用字体完成可评估样稿，再说明需要的动作。字体文件仅在允许再分发时随商品工程带走；技能包不夹带不明来源字体。

所有中文、参数、标注在PS排版；生成模型只做所需图像内容，不生成带最终中文的整张海报再叫它可编辑。参考里确为不可拆的书法装饰时可另做形状/图像效果层，同时保留对应可编辑文字及说明，不能声称装饰像素是原生文字。
