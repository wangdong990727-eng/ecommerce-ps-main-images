# 功能图标：参考、统一参数与事实

## 优先路线

1. 严格复刻先量取实际参考中的线宽、圆角、符号比例、边距和文字位置。用户已确认可复用且有授权的图标，优先直接提取、去背并独立分层；不强制重新画成劣质近似。参考图缺失时不能声称与某个KEEP WARM图标完全一致。
2. 需要原创简单线性图标时，优先统一参数的SVG/原生路径，再由人工视觉核对。圆角方框、黑线、透明背景、无填充只是一种可选样式，不能固定覆盖所有商品和所有参考。
3. AI绘图可作复杂符号/纹理的候选；prompt不保证同风格或真矢量，也不保证能正确写英文。PNG不是SVG；把PNG包进SVG也不是可编辑路径。
4. 找素材时提供功能词+outline/line+stroke/badge检索词；先匹配同一作者/系列并检查实际许可，不把搜索命中当可免费商用或可转发源文件。

## 统一参数与文字

用同一个viewBox、描边、线端/连接、圆角、符号可视区域及标注基线。128×128配2设计单位描边可作测量样例，实际缩放后线宽会变化；按参考和约200px成图缩略测试调整，不把“2px”当任意尺寸下固定粗细。浅色背景可用深线，深色背景可用白线，具体按参考。

广告标签留在PS原生文字层，与SVG符号分开。SVG嵌入智能对象仍须交原始SVG，并说明其没有拆成PS形状层；若需路径级编辑，可在适合的矢量工具修改SVG再替换。中文不交给生图模型烘焙。原生文本并不自动保证字号、断行及英文语义正确。

## 语义和英文是事实的一部分

|功能候选|可用英文示例|限制|
|---|---|---|
|保暖|KEEP WARM|火焰/℃可能被理解为主动加热或温度性能，需结合事实与文案判断；不加未经证实的温度数值|
|掌心防滑|ANTI-SLIP PALM|先核实掌心纹路及实际卖点，图标不代替测试|
|指尖触屏|TOUCHSCREEN COMPATIBLE|核对适用指位/能力；若有既定参考文案则按授权保留|
|抗水/防泼水|WATER RESISTANT|不等同WATERPROOF；不能将中文“防水”机械翻译成完全防水承诺|
|防风|WINDPROOF|需相应商品依据，不因冬季用品自动启用|
|加绒|FLEECE LINED|按实际内里材质；不要固定不自然的Lined Fleece词序|
|弹力袖口|STRETCH CUFF|先确认确有弹力袖口|
|可机洗|MACHINE WASHABLE|必须有对应洗护依据，不能仅凭面料/外观推断|

词库是候选不是强制卖点列表；事实不支持就不放，英文按本品、参考和目标语言修订，不锁定豆包或其他模型的一版表达。

## 重复批量工具

`icon_badges.py`提供8种确定性线性符号的样例，统一样式参数，不联网、不购买素材、不运行生图。先执行：

```text
python scripts/icon_badges.py templates/icon-theme.example.json --out 新图标样例目录 --demo
```

demo文件仅作风格检查，不表示本款有8种功能。用于真实商品时去掉--demo，每项填入存在的fact_source；脚本只检查来源路径存在，内容是否支持功能仍由助手核对。每套先看1–2个再扩展；复杂掌纹、特殊触屏手势仍可能需要重画或授权素材，不能把示例说成参考已完全还原。

同时可按需输出绘图prompt和检索词，但不能“兼容所有模型”或把写出prompt当已生成。可用模板：`minimal outline [功能符号], matching the supplied reference grid, consistent stroke and corner radius, transparent background, no lettering, no gradients or shadow`；模型实际支持多参考/透明背景与否另行验证。
