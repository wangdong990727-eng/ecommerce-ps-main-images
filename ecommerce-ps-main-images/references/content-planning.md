# 只用于 new_design / 已授权 adapt 的内容策划

目的：确定顾客需要知道什么，以及现有证据能够展示什么；不是默认把商品扩成固定屏数。strict_replica保留参考顺序和文案，只使用事实核验方法，不重做故事线。

在现有project-state关联的制作说明里写以下三项；复用已有facts和copy，不另建互相冲突的事实库：

1. **卖点证据**：原始事实/来源 → 对顾客的意义 → 可使用的表达及位置限制。材料外观不能推导防水、恒温、无压感、所有头围适用；用户确认的参数照原口径使用。无可追溯评论时不发明人群痛点或测试结论。
2. **购买疑问**：按本品用途选择主要疑问，例如是否戴得对、尺寸怎么看、内里是什么、有哪些真实色款。顾客疑问是策划假设，和已证实商品事实分开写。通常只围绕当前最影响购买判断的问题展开，避免为了完整堆模块。
3. **逐屏分镜**：页ID、购买疑问、一个主要沟通任务、最终文案对象、证据/素材ID、画面方式、未知项与不允许出现的宣称。一屏一个主要任务是组织方法，不是强制拆屏规则；数量由用途、素材、用户范围决定。adapt中另列允许改动及仍须保留的参考部分。

用一张首屏和一个高风险证据/穿戴屏验证方案能否制作，再扩展；事实不足的卖点直接省略或标缺口。服饰/耳罩缺真人佩戴比例证据时，AI场景只能是候选，不能升级为尺寸适配证明。先锁定已有真实材料；不要为设计新卖点而新增生成图来充当证据。

来源文件名、证据ID、素材状态留在制作记录，不当成商品图上的默认文案。不同颜色样品分别展示内外细节时，可用消费者能理解的实拍颜色/视图标签区分，不让人误认同一色款的正反面；描述性色名不冒充正式SKU名。

完成分镜后走原有布局、素材、PS与验收路径；策划稿完成不能叫商品图完成。资料充分且用户授权持续制作时内部完成，不新增逐屏确认环节。
