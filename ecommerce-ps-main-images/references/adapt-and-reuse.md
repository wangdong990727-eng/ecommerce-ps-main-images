# 非严格模式、母版和局部续改

本文件只在用户明确允许改版、无参考新设计或要求复用母版时使用；不得用它覆盖 strict_replica。

需要从商品资料策划内容时先读[内容策划](content-planning.md)，产出可执行分镜；不为改字或严格复刻启动新策划。

`adapt`：先列用户允许改的范围。可以合并重复信息、改变结尾、调整阅读链；保留参考中明确要求的核心特征。变化在对照报告说明。

`new_design`：按本品事实建立首图、结构/体验证据、使用场景、参数与选择信息。没有依据的功能不设模块；不把手套触屏、防泼水或耳罩折叠强加给别的品类。数量依据用户用途和素材，不固定8–10屏，也不套过去平台张数。用户仅给比例时可采用1200像素工作宽度并说明，这不是已核实的平台上传限制。

母版可复用条件：本次指定的设计适配、产品结构差异可容纳、原生文字和嵌入对象可用、用户认可的范围仍适用。已通过旧版不自动覆盖本次新参考。改字直接改文字；换色SKU直接换真实色款资产；换品类重新检查图片框/蒙版/参数字段，不强塞进手套母版。

局部修改只检查受影响的文字、素材、画幅和整页依赖，不重新执行整套开工问卷。用户集中发截图要求等待时只整理反馈，收到开始信号后统一修改，不能只处理最后一条。

未来新商品沿用统一版式流程，在 product_profile 中记录从实拍看到的结构、穿戴/使用关系、高风险部位、事实来源。缺少品类经验时提高证据要求，不把耳罩或手套检查表当通用事实。
