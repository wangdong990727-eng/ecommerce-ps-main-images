# 同版多色：一个共用PSD

## 图层约定

“各色图层组上下排列”指图层面板中完整组堆叠在同一画布，不是把各色拼成长画布。每组包含该色完整文字、商品/人物嵌入智能对象、蒙版、背景、装饰和投影；默认只显示一组。各色JPG可指向同一个共用PSD，不必重复交一色一个PSD。一个SKU模板、主图模板可分别各一个；不要把完全不同版式硬塞同模板。

同版时人物身份、姿势、佩戴比例、排版、素材框位置保持一致；实际不同颜色的材质光影可自然不同，不用拉伸产品来凑完全相同轮廓。每色商品必须用对应实拍，拼色按各部位核对；不以整体调色冒充该色实拍。

复制颜色组后逐层检查旧色商品、隐藏备选、重复图、投影和共享智能对象联动。需要独立内容的智能对象，采用“通过拷贝新建智能对象”等经验证方式，替换后确认其他颜色未跟着变。按图层ID及唯一资产标记识别目标；PS加“副本”后缀时不依赖整名相等，也不模糊匹配后擅自选第一项。

## 工具：原生合并与ID导出

已有各色完整PSD，且它们同画布/分辨率、RGB 8位、同色彩配置时可使用：

```text
python scripts/psd_variants.py build variants-build.json --out 新任务目录
python scripts/run_photoshop.py 新任务目录/run.jsx --status 新任务目录/status.json
```

配置参照templates/variants-build.example.json。编译只生成JSX，不运行PS。JSX完整复制原生图层，不生成/调色；各组层级、文字、智能对象、蒙版、可见性需实际核对。输入PSD若正在PS中打开，工具拒绝操作，避免保存或关闭用户文档。目标组保存为shared-colours.psd，逐色JPG和稳定group_id记在status.json。工具会开启任务新文档及从磁盘读取的任务源，最后不保存源文件并恢复偏好。

对人工修改后的共用PSD，先快照，再读取实际当前组ID，编写export配置：

```text
python scripts/psd_variants.py export variants-export.json --out 新导出目录
```

模板见templates/variants-export.example.json。export仅从实际磁盘副本打开、按明确顶层组ID逐色导出；拒绝重复/丢失ID与额外顶层对象，不用旧色名称猜测。原PSD不保存，可见性变化仅在任务打开的文档中，结束关闭。ID来自本次读取的PSD；旧文件的ID不自动适用新文件。

已存在输出目录/文件禁止覆盖。build支持PSD、export可读PSD/PSB，但不会自动转换大文件为PSB。色彩配置、未支持色深/模式不匹配时先在任务副本显式处理并核验，不偷偷降级。每色原生文字/智能对象默认至少各1个，可按本页确无文字等事实显式调整最低数，但不能凭此声称拆层完整。

## 人工验收

逐色切换，只显示一个组，从实际交付路径重开后再次导出；核对颜色实拍、衣脸未漂移、排版坐标、蒙版和投影残留。脚本只提供技术计数与导出，不验证颜色语义、同一人物、真假商品、佩戴或视觉通过。

通过测试副本改一行中文，替换一个嵌入素材，检查其他颜色没有被同步替换；替换不同尺寸素材后重查变换/蒙版，不以“保留变换”保证视觉自然。
