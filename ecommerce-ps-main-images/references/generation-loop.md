# 穿戴素材生成与定向返工

目的：在锁定的图片槽里获得符合本品的穿戴素材。允许多次生成，不能靠无限随机重试掩盖没有改善，也不能为好生成而改掉参考构图。

## 生成任务包

每个独立镜头有稳定job ID，在 `generation_jobs` 里关联目标页/图片槽，文件放项目 `generation/<job_id>/`。至少保存：

1. 同角度本品实拍、放大的高风险局部和色款事实；保留文件名及角色。
2. 版式中的画幅、机位/姿势、主体可见框、裁切、留字区和遮挡关系。
3. 人物身份与服装锚点（如要求同一人），背景/光线参考；同行图只负责构图。
4. 商品必须保留项/不能出现项/隐藏未知项、自然穿戴关系。
5. 输出要求：不带广告文字、不画图标和参数，所需分辨率/透明背景，输出位置。
6. 每次实际调用工具/模型、输入、提示词、结果、缺陷、改变了什么、是否改善；没有工具回执不写已生成。

可用的提示词结构：

> 图A是唯一商品事实，图B是机位/构图，图C仅是人物身份（有才写）。制作【job和图片槽】。保持【姿势、主体范围、遮挡、留字区】；商品逐项保留【实拍可见结构】。禁止继承同行的【具体不同结构】。不生成文字/品牌，不改变商品颜色和结构。输出后重点检查【本镜头可见高风险项】。

这只是语义约束，不是产品一致性的证明。宿主支持图像编辑/多参考时按实际接口传图；只支持文字生图时不能假装实现本品参考约束。不能把AI生成首图当后续唯一商品事实源。

## 实拍与生成的分工

- SKU、材料/内里/掌纹/毛绒细节证据，优先本品实拍抠图与近照。
- 人物/环境可生成；人物穿戴区域仍须按本品检查。不能只因为“是场景图”就允许实物失真。
- 能用同角度实拍合成时，保持轮廓、贴合、遮挡、透视和真实接触。贴图不服帖时不能把平面商品硬贴到手/头上。
- 要去背主体就完成去背；毛绒边缘保留真实细毛，不切成硬圆球、不留桌面杂物。工具失败转PS蒙版修边或其他已授权工具。
- 掌纹/标识/耳罩连接点等关键处生图反复变化时，改局部编辑、真实素材合成或补实拍；不能靠遮住本来要求展示的部位来逃过核验。

## 候选、检查、入版分别记录

单一状态链：`planned → generated → inspected_pass / inspected_fail → placed → final_checked`。生成工具记录只写调用结果，审核状态集中在项目记录，不在不同索引相互冲突。

每张候选的检查至少写：对照哪个实拍、哪个可见部位、观察到什么、结论及局部证据文件。不能批量复制“颜色正确、无新增结构”。`inspected_pass` 必须所有本镜头可见的关键项通过；看不清记不可判断，不能记通过。不可见项不强行补画、不算已证实。

生成图先过[品类检查](product-profiles.md)再看人物漂亮、表情、清晰度、场景；商品错不得用美观抵消。入版后再看裁切/比例是否把原合格资产变坏。每图检查商品、人物解剖、穿戴、构图四项，失败项定位到具体局部。

## 重试控制

用户愿意多次生成，不等于授权新增付费API。沿用已有工具与明确额度；新增费用先取得对应授权。任务开头助手给出合理的本轮尝试计划并记录，用户已有额度优先。

默认每个困难图片槽最多进行6次实际生成/编辑调用作为**首轮诊断窗口**，不是6次保证成功，也不是两次后取消镜头。每次选一个主要失败变量修复并锁住已过部分；同一方法连续两次无改善，换同角度锚点、局部编辑、合成或服务能力。工具失败不伪装成候选。

达到首轮窗口仍有硬失败时：保存最好候选与明确差异，继续其他独立页面；若已有证据支持可完成的PS修复则执行。需要更多付费额度、必要实拍、改变指定姿势或降低复刻标准时，集中提出具体缺口，不能默默降级。不存在可行路线时报告该槽blocked，保留完整可视待审版和可继续的任务包。

用户明确允许更多轮时更新窗口并继续；不能每轮都问“是否继续”。每次重试应有新信息或路线变化，不能无限重复同一请求。

## 没有生图能力的宿主

输出以上任务包的 `任务说明.md`、`prompt.txt`、已授权传入的参考图和期望回填文件名。先完成PS锁版和全部已有实拍页面。用户在其他工具生成后放入指定文件，当前助手逐张核验、回填同一对象继续。未补齐之前状态仍是缺素材的待审工程，不是完整成品；不擅自安装服务、配置密钥或宣称其他软件可以稳定生图。

缺图状态固定为ASSET_REQUIRED，恢复使用project_tools的asset-return及页asset_ids依赖，详见[回归验收](regression-acceptance.md)。提示词/参考/保存位置只针对该张图片；占位版或未经本次检查的旧图不得填成READY。
