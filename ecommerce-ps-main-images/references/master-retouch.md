# 清晰母版与定向返修

## 起点与范围

分别保存original（实拍/原始人物）、clean_master（最高质量可用母版）、current_pass（当前人物/商品已通过素材）、adopted（用户针对具体版本采用）与working副本。它们可以指向同一个哈希，但角色不能混淆；不得把最后一次生成自动当清晰母版。

每次从当前用户手改PSD继续前，先快照该实际文件；记录哈希、日期与来源，在副本另存。看清当前图层内容和用户修改，不回旧脚本重建覆盖。若发现噪点、糊化或纹理漂移，回清晰母版，仅合入本轮需要的局部，不把连续多次生成的坏像素反复当输入。

```text
python scripts/asset_workflow.py snapshot 当前手改.psd --out 新快照目录
```

## 保护区与方法选择

- 只改耳包大小：脸、发型、衣服、背景与已确认面料要保护；大小变化后另核对接触、遮挡和比例。
- 只修人物噪点：商品外形、颜色、纹理、包边与连接保护。人物和商品原先混在一个智能对象中，需用PS蒙版隔离保护，或从清晰母版合成该局部；不能宣称已经拆成独立商品层。
- 实拍机位吻合时可合成，但要自然处理透视、光影、贴合、发丝遮挡；硬贴真实商品并不自动自然。AI穿戴也要逐项回对实拍；不能只凭“其他不变”提示词认定没变化。
- 先记录实际生成/编辑范围、参考职责及保护区域。需要时用PS图层蒙版隔离；导出同画布同坐标的PNG检查保护区。不得为了通过差异检查偷偷放大允许改动区或提升容差。

```text
python scripts/asset_workflow.py protected-diff 母版.png 候选.png 允许编辑区.png --out 新证据.json
```

遮罩必须为1/L模式二值PNG，白色允许变化，黑色必须保护；全白拒绝检查。默认逐RGBA通道零容差，不自动缩放、配准、调色；JPEG压缩图不可用于严格像素检查。PASS只表示保护像素没变，不证明修改区域的商品正确；FAIL需定位是否真正越界、导出色彩不同或坐标未对齐，再修复，不能调整阈值掩盖变化。

## 分项复核

人物、商品、佩戴比例、文案、排版、色款分别保留not_run/pass/fail/blocked及具体观察。用户采用只依user_approval原话、版本和范围，不随其他pass自动改变。修改某一部位也要使受影响维度失效：例如耳包变大至少重查商品与佩戴比例，文字变动重查文案与排版。

人物/商品通过后，只在PS中排文字，不重新生成整张图。保持原生中文、留字区域及素材框；未分拆的合成人物/商品、复杂效果、AI背景准确列入交付报告。
