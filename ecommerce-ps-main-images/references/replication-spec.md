# 从参考到固定版式

本文件是 strict_replica 的设计入口。先还原、量取、锁版，再换图；不是先生成海报再尽力贴近。

用户确认复用的参考图标按[图标提取规则](commerce-compliance.md)直接抠取，保留曲线、圆角和线宽，不强制粗略重绘；夸大功能配字及图形暗示独立审核，不随图一并照搬。

## 1. 读完整参考

主图、SKU、详情分开编号。用户指定顺序优先；否则按页面连续性和文件自然排序推断，并在记录注明。`scripts/stitch_reference.py`可做全条诊断图；运行前检查其文件顺序，不能把文件名排序当设计证据。含混合扩展名、长页过大时分段拼接并保存明确的顺序清单。不能只看缩略网格；全条确认节奏，原图局部读字和特效。

切片在一个人物/标题中间断开时先拼回同一画面。为每个逻辑页面建稳定ID；每个参考文件至少有对应页面，必要时一对多或多对一仅表示切片重组。**不能把多个主题合成一页而称为切片重组。** 没有对应参考的新增页独立标明，不冒称复刻。

## 2. 逐对象转录

先确定参考画布 W×H；目标画布最好保持同一宽高比。坐标统一为目标画布像素，参考坐标先按 `target_width / reference_width` 等比换算。只改导出宽度时所有位置、字号、间距和特效等比缩放。用户指定了不同宽高比时，另存适配版并说明差异，不宣称像素相同。

每页的工作记录包含下列信息；可用布局JSON和一小段特殊技巧说明，不另造多套表：

|对象|必须量取/记录|
|---|---|
|背景/照片|满版或图框、图片框坐标、远近、裁切、留字区、渐变/纹理和与下一页的边界|
|人物/产品|可见轮廓的外接框、姿势、头/耳/手方向、实物占比、前后叠放、出框/遮挡关系|
|每段文字|参考原句、手动断行、最终文案、位置与可见宽高、字体类别/字重/倾斜、字号/行距/字距、描边/阴影/反射|
|装饰|形状/路径、位置、大小、旋转、颜色、透明度、与文字和人物的上下层关系|
|证据窗口|形状/裁切、真实来源、边线/标签、小窗占比|
|引导线/图标|起止坐标、指向的真实部位、线宽、线性或实心风格、编号对应|
|连续关系|相邻背景、主体跨界、留白、照片边界；不无故加分隔横条或白雾|

量取值是制作数据，不假称自动精确识别。未读清的字标成待辨认；字体只认出风格时写近似，不编造字体名。主体内容可以替换，图像槽、构图和遮挡要保持；抠图失败不能把原去背主体改成矩形实拍。

本品与参考有必要结构差异时，商品事实优先。例如参考耳罩有长系带、本品无系带：保留耳包/头箍主体锚点和视觉尺度，原系带区域可成为留白，阴影随真实主体；不能拉长、放大本品填满含系带的旧外接框，也不能生成不存在的系带。把这个局部差异明确记录，其他文字、分栏和技巧仍照参考，不借此重设整页。

## 3. 锁版先于填图

用 `render_layout.py --skeleton` 输出带原生文字和装饰的骨架。图片槽使用占位框；特殊剪影/倾斜框必要时在PS补原生路径/蒙版。对照参考检查四类最显眼误差：文字基线和宽度、主体轮廓范围、装饰位置、留白/边界。未通过只修布局，不消耗更多生图。

建议初始制作容差：主要边缘/基线偏差尽量小于画布对应方向的1%，标题可见宽高偏差尽量小于3%；这是查错提示，不是用户批准标准，也不证明审美或产品一致。用实际字体视觉边界校准，不能盲调参数凑分。语义不同的照片不做全图像素相似度评分。严格相同、近似字体、事实替换、未实现技巧分别记。

同一页面所有主要技巧需要逐项存在，例如：手写标题、斜向纸条、去背人物出框、实拍证据小窗、标签引导线。普通粗黑体不能替代手写感；图片矩形框不能替代人物出框；新增大色名不能改变参考层级。无法精确实现时先完成可复核的近似样稿，记录差异，不能默认通过。

## 4. 三类产物分别复刻

- 主图：每张使用自己的参考；不能用首图变字凑满。参考缺失的其他主图在明确授权后单独用new_design项目记录，最终报告关联其去向，不用假参考填空。
- SKU：先选参考对应的一个真实色款作为可编辑样例，核对去背、比例、正反叠放、字体效果与替换动作，再扩展真实色款。不同色款逐一复查结构与颜色，不用AI染色发明色款。多张SKU参考互相冲突时集中说明采用哪版。
- 详情：严格保留原信息顺序、主题数量和结尾；不要因多张都有模特而合并。完成后检查完整参考与完整结果的长版，以及原分辨率局部和接缝。每个分屏独立可用，但不能为分屏好看破坏整页。

## 5. 修改不破坏已锁部分

每次反馈转换为页ID、对象ID、目标、影响范围。改字体检查相邻文本和溢出；改素材检查裁切、蒙版及跨页关系。只改对象及依赖产物，不重建整套。构图或文案发生实质变化时更新该页版本与批准状态，不能沿用旧批准。
