# 精简商品交付与独立素材

用户需要可直接使用和人工修改的成品，不需要阅读制作过程。默认商品目录：

```text
商品_版本/
  01_上架图片/          主图、逐色SKU、详情分屏和完整长图（按本次范围）
  02_做图源文件/        可编辑主图PSD、SKU共用PSD、详情分屏与原生整页PSD/必要PSB
  03_模特与场景素材/    最终采用的无广告文字原尺寸素材、清晰母版及必要可复用局部
  04_字体/              实际使用且许可允许再分发的字体文件与其必要许可文件
  完整交付报告.html
```

无需使用的空类别不建。单独的制作记录与对比目录、上架清单CSV、使用说明、失败候选和中间日志均不交付。字体仅允许使用不代表允许转发字体文件；不能转发的字体在报告写PostScript名、官方获取来源及限制，不打包。不要为满足目录虚构字体许可。

## 素材如何单独重做和替换

模特和场景采用素材必须单独导出/复制，不仅藏在PSD智能对象里。保留原尺寸及实际已有透明度；不为“无文字”重新生成已通过的人脸或商品。实际无法分开的模特+商品合成图可整张交，并在报告注明；不能承诺生成区域已独立拆分。

报告用短表列素材ID、采用版本、对应PSD/色组/智能对象ID、所需画幅与替换注意点，方便直接找到文件。需要重新抽卡时，在该采用素材/清晰母版基础上准备最小参考和局部变化要求；返工图先重新验收商品及人物，再替换PS对象。模板见templates/asset-replacement.example.json，可作为内部数据驱动报告，不另向用户交制作记录。

交付报告只放最终预览、文件入口、人工编辑映射、实际拆层范围、字体、已知限制和采用/待人工处理的范围；不放整套前后对比、过程流水、抽卡日志或重复说明书。完整内部对照检查仍在制作时执行，缩略图不得代替整条详情核验。

## 完成后清理

先保存成品、核对完整交付、重开PSD逐色测试和复制哈希；仍有待修/阻塞则保留必要工作资料方便续接，不提前删除。完成后可删除本次任务自建的临时对比、测试副本、失败生成与重复导出，先检查这些路径未被最终PSD/报告/素材引用，且全部位于已明确的本次工作目录。删除前验证绝对目标及依赖，不整盘递归清理。

不删原始实拍、参考原件、用户手改、清晰母版、采用素材、最终成品或任何历史项目。保留能定位当前成品与采用状态的最小台账/报告，不保留无用全过程；如清理改变证据路径，更新最小台账引用，不能留下假证据。用户本轮对未来交付的简化不代表授权删除截图中历史目录。

## 经验复用

一张主图或一段详情做完可提炼可复现的经验：触发条件、有效做法、实际证据、限制。只将通用规则或可复用脚本纳入技能版本；单款参数、颜色、风格、一次失败不升格为所有商品规则。技能改动先备份、验证、形成独立版本；不自动修改其他记忆库或向远端推送。经验结论不要求用户收一份制作过程包。

技能开发本身的修改清单/测试结果/已知限制是本次技能交付要求，仍保留；不要把“商品不交过程”误用成隐瞒技能脚本未测试状态。
