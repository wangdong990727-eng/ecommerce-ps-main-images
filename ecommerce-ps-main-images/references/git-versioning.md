# Git安装、升级与回滚

通用技能适合独立Git仓库：保留稳定name ecommerce-ps-main-images，以提交和版本标签区分版本。根目录保留技能文件夹，AI可按仓库内路径安装；不要把机器路径、商品工程、PS暂存、账号或密钥入库。

用户授权发布到GitHub后才创建/推送远端。默认独立私有仓库；私有库不会出现在公共搜索，另一台电脑的AI需使用有该仓库访问权的账号/git凭据。不能承诺任意AI仅凭URL无需登录就能安装；若需要无账号公开安装，由用户明确决定公开范围与许可。

安装提示应给出真实仓库URL、技能子目录ecommerce-ps-main-images、明确ref以及name。目标助手检测其技能目录，先备份已有同名技能到搜索路径外，避免安装两份；下一轮重新加载并读版本。Codex具备skill-installer时可用其install-skill-from-github.py传--repo、--path、--ref；不要硬编码本机安装脚本路径到跨机提示。

升级：先备份当前技能和手改，获取指定新标签，核对版本/文件，再跑目标机技术/PS小样。回滚：安装上一个明确标签或恢复备份；商品工程和用户PSD不跟随技能回滚，不删除本机其他技能。源码可见并不等于字体、同行图、商品素材许可一并开放。

本仓库的tests及验证结论分技术编译、PS实跑、真实商品视觉与用户采用；尚未执行的机型/PS版本保持未测，不把GitHub上传成功称为技能已在所有电脑可用。
