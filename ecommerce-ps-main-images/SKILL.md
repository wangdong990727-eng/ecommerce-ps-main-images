# 电商严格复刻与可编辑交付

目标：把参考变成可重复执行的版式，把本品实拍变成逐项可核对的商品约束。技能不能使图像模型必然还原商品；不得把写了提示词、生成成功、PSD可打开说成复刻通过。

国内商品图先读[素材、文案、字体与平台要求](references/commerce-compliance.md)：用户确认复用的图标直接抠取并独立分层，不强制劣质重画；夸大功能及图标暗示单独替换。默认免费商用许可明确的字体；营销文案不用极限措辞，不带其他平台背书/引流。保留有依据的规格及必要提示，不用简单禁词表误删事实。

## 先选模式，禁止混用

|本次用户意图|模式|允许改变什么|
|---|---|---|
|复刻、照着做、尽量完全一致|`strict_replica`，默认|锁定信息顺序、比例、字级、节奏与展示逻辑；保留适合本品的表达，替换品牌、事实及受保护的标识/独创素材|
|参考风格但允许改版|`adapt`|在用户给定范围内调整内容和设计，并说明变化|
|没有参考的新设计|`new_design`|按商品事实和用途自行设计|

严格复刻中不得自行压缩到8–10屏、合并重复镜头、强制选色收尾、统一首屏风格、增加新创意或重写营销文案。参考切片数量不等于设计模块数量：可以为导出重新切片，但完整画面的顺序、占比和节奏保留。用户后来明确的局部修改仅覆盖对应项。

## 执行入口

1. **读取已有材料。** 优先用户路径；否则找真实桌面的相关候选文件夹。先看实拍、参考、已有参数/反馈；候选不唯一才集中问一次。只做SKU或改字不启动无关全套。旧任务状态不自动成为新任务批准。
2. **检测能力。** 读[跨软件执行](references/executor-adapter.md)，核实图片可视检查、PS、Python/依赖、字体、生图和可写路径。运行 `scripts/project_tools.py preflight --out <检测.json>`；字体在首次PS小样中核对。没有可用生图能力时，缺失素材标记 `ASSET_REQUIRED`，输出独立任务包；先继续抠图、锁版和已有素材页，禁止占位或旧图冒充合格素材。
3. **集中确定关键缺口。** 平台/用途、参考次序、实际色款、必须写入的参数、已有授权。可从资料确定的不用问；模特候选数量、普通配色与制作细节由助手安排。默认连续内部自检做到完整待审包，不逐屏让用户批准。只在商品事实矛盾、缺少必要实拍、费用/工具或改动超出原要求时补问。
4. **建立可续接记录。** `scripts/project_tools.py init <项目>`，按[项目记录](references/project-record.md)填写 `project-state.json`。每页稳定ID、参考、文案、布局文件、素材、检查证据和下一动作在这里关联；不要多份索引各写一个审核状态。小改沿用已有记录、只更新受影响项。

## 固定制作顺序

|步骤|留下什么|助手怎样判断可以继续|
|---|---|---|
|参考复原|完整按序参考长版、逐页清单；主图/SKU单独映射|实际看过全条及文字局部，切片顺序已核对，没有默默漏屏|
|实拍锁定|本品事实/角度/色款表，禁止变化项|读[商品品类](references/product-profiles.md)，区分观察到、用户证实、未知|
|逐页量取与抄字|每页布局JSON、文案原文与必要事实差异|按[复刻规格](references/replication-spec.md)记录元素位置、裁切、层级及技巧；按[文字](references/typography-copy.md)保留原句与断行|
|锁版样稿|原生文字/装饰/图片占位框的PS预览|和参考等比例对照；每种独立版式都检查，不能只靠第一张通过|
|穿戴与商品资产|每个图片槽的候选、真实锚点、具体检查结果|按[生成闭环](references/generation-loop.md)，商品/佩戴不合格不能入版；生图返工不改变锁版|
|填入与扩展|逐张JPG、原生PSD、完整详情与可编辑整页|先验证一个SKU及有风险的连续区段，再按已锁布局扩展；PS顺序执行|
|全套核验与交付|逐页/整页对照报告、检查证据、问题及状态|按[验收交付](references/acceptance-delivery.md)分别检查布局、文案、商品、技术；用户验收独立记录|

这是一套内部制作顺序，不是七次人工确认。发现内部错误先自主修复；缺图时完成所有不依赖它的工作。不得为“流畅”带着已知错误批量扩展，也不得把完整项目停在文字规划。

无参考新设计、允许改版时，先按[内容策划](references/content-planning.md)形成卖点证据、购买疑问与逐屏分镜，再进入相同的原生制作路径。strict_replica不运行重排策划；只做事实替换与联合复审。

## 原生执行与复用

PS制作读[Photoshop执行](references/photoshop-workflow.md)和[布局JSON](references/layout-schema.md)。`scripts/render_layout.py`把测量后的JSON编译成JSX；`--skeleton`先检查版式。文字保持原生，商品/人物为嵌入智能对象，图框有真实蒙版，装饰/效果独立。编译器不是自动识图或自动抠图工具；复杂笔刷、路径、变形等超出其能力时用原生PS补全并记录，不能静默简化。

主图每张按其参考；SKU复用通过的布局、逐色替换本品实拍和事实字段；详情按完整参考连续重建。跨画幅单独设布局，不拉伸和机械裁切。只有用户明确要新设计时才使用[无参考与适配](references/adapt-and-reuse.md)的默认设计方法。

后续改字只改文字层，修模特只替换对应素材；影响到的分屏、其他画幅、整页和报告一起更新。已有合格资产和不相关页保持冻结。源图、旧交付和用户手改文件受保护。

## 完成与停止的边界

- 检查脚本只能检查记录、路径、配对和状态，不能证明视觉一致。实际打开结果对照，禁止同一句“已看过”复制给所有资产。
- 同一方法连续两次没有改善就诊断换方法，**不是两次后自动放弃参考**。可在已有授权内继续局部编辑、换实拍角度、合成或生成；具体预算与停止条件见生成闭环。
- 换成别的姿势、去掉特写、改矩形照片来替代去背主体，会改变复刻要求：不得隐瞒替代，也不得先改完再宣称一致。
- 完整待审包可以含明确标出的局部阻塞；正式可上架包不能夹带未知参数或商品错误。用户“人工改改能用”只记录人工接手范围。
- 本轮优先适配SK滑雪手套与后戴式毛绒耳罩；后戴结构不得替换为头顶式。旧头戴式耳罩试用记录不能证明后戴式通过。主图、详情、SKU独立验收，借助 `asset_ids` 共用相同已检查素材。
- 固定回归为手套真实页、后戴式耳罩素材/SKU页、缺生图暂停恢复。按[回归验收](references/regression-acceptance.md)留证据，结果仅为 `PASS/PARTIAL/FAIL`；缺真实素材或未执行不能记PASS。
- 本次技能包可直接交付；商品测试稿可按用户要求直接放桌面并标待验收。正式商品包在本次批准后复制校验。技能不授权发布、付费服务或删除历史项目。
